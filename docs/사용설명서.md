# 웜뱃 블록코딩 사용설명서

KIPR **Wombat** 로봇을 크롬에서 **한글 블록**으로 코딩하고, Python 코드로 바꿔 Wombat에서 바로 실행하는 웹앱의 사용 방법입니다.

- 왼쪽: 블록 편집기 / 오른쪽: 실시간 Python 코드 · 실행 결과 · 연결·도움말
- 인터넷 없이도 동작합니다 (필요한 라이브러리를 파일 하나에 모두 담았습니다).
- Wombat의 프로그래밍 서버 **두 종류(최신 KIPR Software Suite, 예전 Harrogate)**를 자동으로 알아보고 지원합니다.

## 1. 구성 파일

| 파일 | 설명 |
|---|---|
| `index.html` (배포 패키지에서는 `wombat-blocks.html`) | 웜뱃 블록코딩 웹앱 (이 파일 하나로 동작) |
| `wombat-relay.py` | **연결 도우미** — 예전 펌웨어(Harrogate) Wombat에 연결할 때 사용 |
| `웜뱃연결.command` | Mac에서 더블클릭으로 연결 도우미 실행 |
| `웜뱃연결.bat` | Windows에서 더블클릭으로 연결 도우미 실행 |

연결 도우미는 웹앱 파일과 **같은 폴더**에 있어야 합니다.

## 2. 준비물

- 전원이 켜진 KIPR Wombat
- 크롬 브라우저가 있는 컴퓨터 (Mac 또는 Windows)
- 연결 방법에 따라: Wombat Wi-Fi 또는 **랜선** (노트북에 랜 포트가 없으면 USB-이더넷 어댑터)
- 예전 펌웨어(Harrogate) Wombat이면: **Python 3** (Mac은 터미널에서 `python3` 실행 시 설치 안내가 나옵니다)

## 3. 내 Wombat 버전 확인하기

컴퓨터를 Wombat에 연결한 뒤([4장](#4-컴퓨터와-wombat-연결하기)), 크롬에서 `http://Wombat주소:8888`을 엽니다.

| 화면에 보이는 것 | 서버 종류 | 웹앱 여는 방법 |
|---|---|---|
| Information에 **"Harrogate version: 1.0.1"** 등 | **Harrogate** (예전 펌웨어, 예: Firmware 31.2.0) | **연결 도우미**로 열기 ([6-2](#6-2-예전-펌웨어harrogate-연결-도우미로-열기)) |
| KIPR Software Suite 새 화면 | **KIPR Software Suite (Voldigate)** (최신 WombatOS) | 웹앱 파일을 바로 열기 ([6-1](#6-1-최신-wombatos-웹앱-파일을-바로-열기)) |

> 어느 쪽인지 모르겠으면 연결 도우미로 여세요. 두 종류 모두 동작합니다.
> Harrogate는 브라우저가 다른 주소에서 접속하는 것을 허용하지 않기(CORS) 때문에, 파일로 연 웹앱으로는 직접 연결되지 않습니다.

## 4. 컴퓨터와 Wombat 연결하기

Wombat 화면의 **About(정보)** 에서 접속 정보를 확인할 수 있습니다.

### 4-1. Wi-Fi로 연결

1. Wombat About(또는 Network) 화면의 **SSID**와 **Password**를 확인합니다.
2. 컴퓨터를 그 Wi-Fi에 연결합니다. "인터넷 없음" 표시는 정상입니다.
3. Wombat 주소: **`192.168.125.1`** (About의 WiFi 줄)

### 4-2. 랜선으로 연결

1. Wombat **About** 화면에서 **Event Mode**를 켭니다. (Event Mode를 켜면 Wombat의 Wi-Fi는 꺼집니다)
2. 랜선으로 **컴퓨터와 Wombat을 바로** 연결합니다. (학교 벽면 랜 포트·허브가 아님)
3. 10초쯤 기다린 뒤 Home에 갔다가 About을 다시 열어 **LAN** 줄을 확인합니다.

| LAN 줄 | 의미 | 할 일 |
|---|---|---|
| `192.168.124.1` | 정상 | Wombat 주소는 `192.168.124.1` |
| `0.0.0.0` | 케이블 연결이 감지되지 않음 | 케이블·어댑터를 다시 꽂거나 바꿔 보기 |
| 다른 주소 | 컴퓨터가 아닌 학교망·허브에 꽂힘 | 컴퓨터에 바로 꽂기 (또는 그 주소 사용) |

4. 컴퓨터 쪽 상태 확인

**Mac**: 시스템 설정 → 네트워크 → 유선 항목(예: *이더넷*, *USB 10/100/1000 LAN*, *AX88179A*)

| 표시 | 의미 / 할 일 |
|---|---|
| 🟢 연결됨, IP `192.168.124.x` | 정상 |
| 🟡 자체 할당 IP (`169.254.x.x`) | 주소를 못 받음 → [5장](#5-인터넷도-같이-쓰기)처럼 **수동 IP** 설정 |
| 🔴 연결되지 않음 | 케이블 신호 없음 → 케이블·어댑터 다시 꽂기·교체, 어댑터는 맥북 본체 포트에 직접 |

**Windows**: 명령 프롬프트에서 `ipconfig` → "이더넷 어댑터"의 IPv4 주소가 `192.168.124.x`이면 정상

5. 연결 테스트 (터미널 / 명령 프롬프트)

```bash
ping -c 4 192.168.124.1      # Mac
ping 192.168.124.1           # Windows
```

응답이 오면 케이블 연결은 정상입니다.

## 5. 인터넷도 같이 쓰기

Wombat Wi-Fi에는 인터넷이 없습니다. 인터넷을 쓰면서 Wombat을 제어하려면 **Wombat은 랜선, 인터넷은 학교 Wi-Fi**로 연결합니다.

랜선으로 연결하면 Wombat이 자신을 "게이트웨이(라우터)"로 알려 주기 때문에, 컴퓨터가 인터넷 요청을 Wombat 쪽으로 보내 **인터넷이 끊길 수 있습니다.** 아래 중 하나로 해결합니다.

**방법 A — 서비스 순서 바꾸기 (Mac, 간단)**
시스템 설정 → 네트워크 → 목록 아래 **⋯ → 서비스 순서 설정…** → **Wi-Fi를 맨 위로** → 확인

**방법 B — 랜선 IP를 수동으로 (게이트웨이 비움)**

| | 설정 위치 | 값 |
|---|---|---|
| Mac | 네트워크 → 유선 항목 → **세부사항… → TCP/IP** → IPv4 구성: **수동** | IP `192.168.124.10` · 서브넷 `255.255.255.0` · **라우터 비움** |
| Windows 11 | 설정 → 네트워크 및 인터넷 → 이더넷 → IP 할당 **편집** → **수동**, IPv4 켜기 | IP `192.168.124.10` · 서브넷 `255.255.255.0`(접두사 24) · **게이트웨이·DNS 비움** |

> 수업이 끝나고 그 컴퓨터를 학교 유선 인터넷에 꽂을 때는 IP 할당을 다시 **자동(DHCP)** 으로 돌려놓으세요.

## 6. 웹앱 열기

### 6-1. 최신 WombatOS: 웹앱 파일을 바로 열기

`index.html`(또는 `wombat-blocks.html`)을 **크롬**으로 엽니다. (더블클릭, 또는 크롬 창으로 끌어다 놓기)

### 6-2. 예전 펌웨어(Harrogate): 연결 도우미로 열기

**Mac**

1. 압축을 푼 폴더에서 `웜뱃연결.command`를 더블클릭합니다.
2. 처음에 **"'웜뱃연결.command'을(를) 열지 않음"** 창이 뜨면 **[완료]** 를 누르고(휴지통으로 이동 ❌), 아래 중 하나를 합니다.
   - **터미널에서 실행 (추천)**: 터미널을 열고 `cd ` 입력 후 폴더를 터미널 창에 끌어다 놓고 엔터 →
     ```bash
     python3 wombat-relay.py 192.168.124.1
     ```
   - **다음부터 더블클릭 허용**: 위처럼 폴더로 이동한 뒤 한 번만 실행
     ```bash
     xattr -dr com.apple.quarantine .
     ```
   - **시스템 설정**: 개인정보 보호 및 보안 → 아래쪽 "차단되었습니다" 옆 **[그래도 열기]**
3. "로컬 네트워크의 기기에 연결"을 물으면 **허용**을 누릅니다.

**Windows**: `웜뱃연결.bat`를 더블클릭합니다. (Python이 없으면 python.org에서 설치)

도우미가 켜지면 터미널에 아래가 나오고, 크롬에 **`http://localhost:8765`** 가 자동으로 열립니다.

```
🤖 웜뱃 연결 도우미가 켜졌습니다
   웹앱 주소 : http://localhost:8765/
   Wombat    : 192.168.124.1:8888
```

- 웹앱을 쓰는 동안 **터미널 창은 열어 둡니다.**
- 끌 때는 **Control+C** (⚠️ Control+Z는 끄지 않고 *일시정지*만 합니다)
- 실수로 Control+Z를 눌렀다면: 터미널에서 `pkill -9 -f wombat-relay.py` 입력 후 다시 실행 (Windows는 창을 닫았다가 다시 실행)

### 6-3. claude.ai에 게시된 페이지

블록 코딩과 코드 복사는 되지만, 보안 정책 때문에 **Wombat에 연결할 수 없습니다.** 연결하려면 위 6-1 또는 6-2를 사용하세요. (GitHub Pages 등 https로 올린 페이지도 마찬가지)

## 7. Python 프로젝트 만들기

웹앱은 Wombat에 있는 **Python 프로젝트의 `src/main.py`** 에 코드를 저장하고 실행합니다. 처음 한 번 프로젝트를 만들어 둡니다.

**Harrogate (KISS IDE)**

1. 크롬 새 탭에서 `http://192.168.124.1:8888` (도우미 주소가 아닌 Wombat 주소)
2. **KISS IDE** 열기
3. 오른쪽 **Project Explorer** → 사용자 선택 (학생별 사용자는 **+** 로 추가)
4. **Add Project** → 이름 입력(예: `blocks`) → **Language: Python** → 확인

**KIPR Software Suite (최신)**: `Wombat주소:8888` → 사용자 선택 → 새 프로젝트 → 언어 **Python**

> ⚠️ 연결한 프로젝트의 `main.py`는 웹앱 코드로 **덮어써집니다.** 블록코딩 전용 프로젝트를 따로 만들어 쓰세요.

## 8. 웹앱을 Wombat에 연결하고 실행하기

1. 상단 **[Wombat 연결]** 을 누릅니다.
2. 주소를 고릅니다: **🔌 랜선 직접 연결 · 192.168.124.1** 또는 **📶 Wi-Fi · 192.168.125.1** (빠른 선택을 누르면 바로 연결 확인)
3. "✅ 연결됨 (Harrogate)" 또는 "✅ 연결됨 (KIPR Software Suite)"가 나오면 **사용자**와 **Python 프로젝트**를 고릅니다.
4. **[이 프로젝트로 연결]** → 상단 버튼에 `사용자 / 프로젝트`가 표시됩니다.
5. **[▶ 실행]** (단축키 **Ctrl+Enter** / Mac **⌘+Enter**)
   - main.py 저장 → 문법 검사 → 실행 순서로 진행되고, **실행 결과** 탭에 Wombat 출력이 실시간으로 나옵니다.
   - 문법 오류가 있으면 실행하지 않고 오류 줄을 보여 줍니다.
6. **[■ 정지]** → 프로그램이 멈추고 모든 모터가 꺼집니다.
7. **⬆ 보내기만** (실행 결과 탭): 저장과 문법 검사만 하고 실행하지 않습니다. Wombat 화면의 Programs에서 실행할 수 있습니다.

> 첫 실행은 바퀴가 바닥에 닿지 않게 로봇을 **들어 올린 상태**로 해 보세요.

### 연결 없이 쓰기 (코드 복사)

**[코드 복사]** → Wombat 프로그래밍 화면(`주소:8888`)의 Python 프로젝트 편집기에 붙여넣기 → 저장 → 실행

## 9. 블록 코딩하기

### 기본 사용

1. 왼쪽 메뉴에서 블록을 끌어와 **"▶ 프로그램 시작"** 블록 안에 끼웁니다. (시작 블록에 연결되지 않은 블록은 흐리게 표시되고 코드에 들어가지 않습니다)
2. 오른쪽 **Python 코드** 탭에서 코드가 바로 바뀌는 것을 확인합니다.
3. 작업은 브라우저에 **자동 저장**됩니다. 파일로 보관하려면 **[저장]**(.json), 다시 열려면 **[불러오기]**.
4. **[예제]** 에서 예제를 불러올 수 있습니다.

### 블록 메뉴

| 메뉴 | 주요 블록 (KIPR 함수) |
|---|---|
| 시작 | 프로그램 시작, 빛 센서로 출발 신호 기다리기(`wait_for_light`), N초 후 자동 종료(`shut_down_in`) |
| 모터 | 모터 회전(`motor`), 양쪽 바퀴 구동, N밀리초 이동 후 정지, 끄기(`off`)·브레이크(`freeze`)·모두 끄기(`ao`), 틱 단위 제어(`mav`·`mrp`·`mtp`·`bmd`), 위치값(`gmpc`·`cmpc`) |
| 서보 | 서보 켜기/끄기(`enable_servos`), 위치 설정(`set_servo_position`), 천천히 이동, 현재 위치 |
| 센서 | 아날로그 값(`analog`), 디지털 눌림(`digital`), 터치 대기(`wait_for_touch`), 가속도·자이로·지자기, 자이로 보정, 배터리 |
| 버튼 | A·B·C·X·Y·Z 버튼 눌림 / 누를 때까지 기다리기, X·Y·Z 버튼 보이기 |
| 시간 | 밀리초·초 기다리기(`msleep`), 현재 시간(`seconds`) |
| 화면·소리 | 화면에 출력(`print`), 화면 지우기, 삐 소리 |
| 카메라 | 카메라 켜기, 색상 설정 불러오기, 새 영상 가져오기, 채널별 물체 수·중심·면적·신뢰도 |
| Create 3 | 연결, 직진(m)·회전(도)·곡선 주행, 속도 설정, 동작 끝날 때까지 기다리기, 도킹, 센서 |
| Create (구형) | 연결/끊기, 바퀴 속도, 직진·회전, 범퍼·거리·각도·낭떠러지 센서 |
| 논리·반복·수학·텍스트·변수·함수 | 조건, 계속 반복하기, N번 반복, 계산, 변수, 함수 만들기 |

### 포트와 값의 범위

| 장치 | 포트 | 값 |
|---|---|---|
| 모터 | 0 ~ 3 | 속도 −100 ~ 100 % · mav/mtp −1500 ~ 1500 틱/초 (약 1500틱 = 1바퀴) |
| 서보 | 0 ~ 3 | 위치 0 ~ 2047 (가운데 약 1024, 사용 전 **서보 켜기**) |
| 아날로그 센서 | 0 ~ 5 | 0 ~ 4095 (빛·거리 센서) |
| 디지털 센서 | 0 ~ 9 | 0 / 1 (터치 센서) |

```python
#!/usr/bin/python3
import os, sys
sys.path.append("/usr/lib")

def main():
    print('안녕, 웜뱃!', flush=True)
    motor(0, 80)
    ...

if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:  # [정지] 버튼
        pass
    finally:
        ao()  # 프로그램이 끝나거나 정지되면 모든 모터 끄기
```

- KIPR Software Suite의 Python 템플릿(`from kipr import *`)을 따릅니다.
- 프로그램이 끝나거나 [■ 정지]를 누르면 **모든 모터가 꺼집니다.**
- KIPR 함수는 정수만 받으므로, 계산식·변수가 들어가면 자동으로 `int()`로 감쌉니다.
- `print(..., flush=True)`로 출력이 Wombat 화면과 실행 결과 탭에 바로 보입니다.
- 한글 변수·함수 이름을 그대로 쓸 수 있습니다.

## 11. 문제 해결

| 증상 / 메시지 | 원인 | 해결 |
|---|---|---|
| Mac 네트워크에서 유선 어댑터가 🔴 **연결되지 않음** | 랜선 신호 없음 | 케이블·어댑터 다시 꽂기·교체, Wombat 전원 확인 |
| 🟡 **자체 할당 IP** (169.254.x.x) | 주소를 못 받음 | 수동 IP `192.168.124.10` / `255.255.255.0` |
| 랜선 연결 후 **인터넷이 안 됨** | 기본 경로가 Wombat 쪽으로 감 | [5장](#5-인터넷도-같이-쓰기): Wi-Fi를 서비스 순서 맨 위로 또는 수동 IP(게이트웨이 비움) |
| ping은 되는데 크롬에서 `주소:8888`이 안 열림 | macOS의 로컬 네트워크 권한 | 시스템 설정 → 개인정보 보호 및 보안 → **로컬 네트워크** → Google Chrome 켜기 → 크롬 ⌘Q 후 재실행 |
| `주소:8888/get-users` → **Cannot GET /get-users** | Wombat이 예전 IDE(Harrogate) | 연결 도우미로 웹앱 열기 ([6-2](#6-2-예전-펌웨어harrogate-연결-도우미로-열기)) |
| "Wombat은 찾았지만 … **Harrogate**는 … 직접 접속하는 것을 허용하지 않습니다" | 파일로 연 웹앱 → Harrogate (CORS) | 연결 도우미로 웹앱 열기 |
| "Wombat에 접속할 수 없습니다" | 네트워크 연결·주소 문제 | [4장](#4-컴퓨터와-wombat-연결하기) 순서대로 확인 (LAN 줄, ping, 주소) |
| "연결 도우미가 응답하지 않습니다" | 도우미가 꺼짐·일시정지 | 터미널에서 도우미 다시 실행 |
| "연결 도우미가 이미 켜져 있습니다" | 다른 창에서 도우미가 실행 중 | 그대로 `http://localhost:8765` 사용 |
| "포트 8765을(를) 다른 프로그램(또는 Control+Z로 멈춘 도우미)이 쓰고 있습니다" | Control+Z로 일시정지된 도우미 | `pkill -9 -f wombat-relay.py` 실행 후 다시 실행 (`kill %1`은 같은 창에서만 됨) |
| **'웜뱃연결.command'을(를) 열지 않음** | macOS Gatekeeper | [완료] → 터미널에서 `python3 wombat-relay.py` 또는 `xattr -dr com.apple.quarantine .` |
| `python3`가 없다고 나옴 | Python 미설치 | Mac: 뜨는 설치 안내를 따르거나 터미널에서 `xcode-select --install`, Windows: python.org에서 설치 |
| "… 사용자에게 **Python 프로젝트가 없습니다**" | Python 프로젝트 없음 (C 프로젝트만 있음) | [7장](#7-python-프로젝트-만들기)에서 Python 프로젝트 만들기 → 연결 확인 다시 |
| "❌ 문법 오류가 있어 실행하지 않았습니다" | 코드 오류 | 표시된 줄 번호를 Python 코드 탭에서 확인 |
| 실행 중 "연결이 끊겼습니다" | Wombat 전원·네트워크 끊김 | 연결 상태 확인 후 다시 연결 |
| 모터가 계속 돔 | 프로그램이 비정상 종료 | [■ 정지] 또는 Wombat 화면에서 정지 |
