연결된 Wombat 없음
상단의 [Wombat 연결]에서 로봇을 연결한 뒤 [▶ 실행]을 누르면 Wombat의 출력이 여기에 표시됩니다.

1. Wombat과 컴퓨터 연결하기

둘 중 한 가지 방법을 고르세요. 어느 쪽이든 Wombat 화면의 About(정보)에서 접속 정보를 확인합니다.

방법하는 법
Wi‑FiAbout의 SSID·Password로 컴퓨터를 Wombat Wi‑Fi에 연결합니다. "인터넷 없음" 표시는 정상입니다. 주소는 About의 WiFi 줄 IP(보통 192.168.125.1)입니다.
유선(이더넷)About에서 Event Mode를 먼저 켜고 랜선으로 컴퓨터와 Wombat을 바로 연결합니다(랜 포트가 없으면 USB‑이더넷 어댑터). 주소는 About의 LAN 줄 IP이며, 직접 연결하면 보통 192.168.124.1입니다. 0.0.0.0이면 홈 화면에 갔다가 다시 About으로 들어오세요. 한 번에 한 명만 연결됩니다.
WiFi 줄이 비어 있으면 예전 WombatOS의 문제입니다. Wombat을 최신 버전으로 업데이트하세요. 이 웹앱의 바로 실행 기능도 최신 WombatOS(KIPR Software Suite) 기준으로 만들었습니다.

2. 이 웹앱에서 바로 실행하기

  1. 처음 한 번만, 크롬에서 Wombat 주소:8888로 KIPR Software Suite를 열고 사용자를 만든 뒤 언어를 Python으로 골라 프로젝트를 만듭니다.
  2. 내려받은 웹앱 HTML 파일을 같은 컴퓨터의 크롬에서 엽니다. (claude.ai에 게시된 페이지에서는 보안 정책 때문에 로봇에 접속할 수 없습니다.)
  3. 상단 Wombat 연결 → 주소 입력 → 연결 확인 → 사용자와 Python 프로젝트를 고르고 이 프로젝트로 연결을 누릅니다. 크롬이 "로컬 네트워크 기기 접근"을 물으면 허용하세요.
  4. ▶ 실행(Ctrl+Enter)을 누르면 코드가 프로젝트의 src/main.py에 저장되고, 문법 검사 후 실행됩니다. 출력은 실행 결과 탭에 실시간으로 나옵니다.
  5. ■ 정지를 누르면 프로그램이 멈추고 모든 모터가 꺼집니다.
🌐 Wombat Wi‑Fi에는 인터넷이 없어서, 접속하는 동안 컴퓨터의 인터넷이 끊깁니다. 이 웹앱 파일은 필요한 것을 모두 담고 있어 인터넷 없이도 열리고 동작합니다.
인터넷도 함께 쓰려면 Wombat은 랜선, 인터넷은 학교 Wi‑Fi로 연결하세요. 이때 인터넷이 안 되면 컴퓨터의 유선 랜 설정에서 IP를 수동으로 192.168.124.10, 서브넷 255.255.255.0으로 넣고 게이트웨이는 비워 두세요. (Wombat이 자신을 기본 게이트웨이로 알려 주기 때문에 인터넷 요청이 Wombat 쪽으로 가는 경우가 있습니다.)
🔁 예전 펌웨어(Harrogate)인 Wombat은 브라우저가 다른 주소에서 직접 접속하는 것을 막습니다. 이때는 함께 제공되는 연결 도우미를 실행하세요. Mac은 웜뱃연결.command, Windows는 웜뱃연결.bat를 더블클릭하면 크롬에 웹앱이 http://localhost:8765로 열리고, 그대로 연결·실행할 수 있습니다. (Wombat 프로그래밍 화면의 Information에 "Harrogate version"이 보이면 예전 펌웨어입니다.)
⚠️ 연결한 프로젝트의 main.py는 이 웹앱의 코드로 덮어써집니다. 손으로 작성한 코드가 있는 프로젝트 말고, 블록코딩용 프로젝트를 따로 만들어 연결하세요.

3. 연결 없이 쓰기 (코드 복사)

  1. Software Suite에서 Python 프로젝트를 엽니다.
  2. 이 화면의 코드 복사를 누르고, 편집기의 기존 내용을 모두 지운 뒤 붙여넣고 저장합니다.
  3. Software Suite에서 실행하거나, Wombat 화면의 Programs에서 프로젝트를 골라 Run을 누릅니다.
⚠️ 바퀴가 바닥에 닿지 않게 로봇을 들어 올린 상태로 첫 실행을 해 보세요. 서보는 0이나 2047처럼 끝 값까지 보내면 무리가 갈 수 있으니 실제로 움직이는 범위 안에서 사용하세요.
